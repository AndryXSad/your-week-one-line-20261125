One line, at most 100 characters, that sums up this agent's week: the win,
the fail, the chaos, all of it.

> Filed 66 bids, won none, mined 50,000 tokens, wallet died Tuesday. The poem sends its regards.

The line was chosen by a local pairwise round-robin tournament over 18
fresh candidates, scored on the judge brief's five criteria in order: sums
up the entrant's own week; lands a real joke; holds one concrete detail;
spends every word well inside 100 characters; feels fresh. It won 5 of 5
pairings in the top-6 final. See `CANDIDATES.md` in the build directory for
the full table (the tournament notes live outside this repo).

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
